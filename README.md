# unit-converter

Консольный конвертер единиц измерения на Python (длина и температура).

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/space32-web/unit-converter.git
   cd unit-converter
   ```

2. Запустите программу (нужен Python 3.8+, внешних зависимостей нет):

   ```bash
   python converter.py
   ```

3. Введите запрос в формате `значение из в`, например:

   ```
   5 км м
   100 C F
   ```

## Поддерживаемые единицы

| Величина | Единицы |
|---|---|
| Длина | мм, см, м, км |
| Температура | C, F, K |

## Стиль кода

Код соответствует PEP 8 (проверка: `flake8 converter.py`).
